**Decisions made:**

- **Methodology brief is a standing asset, not a per-audit deliverable.** Lives in `docs/`, not in the project bin. Read once by a prospect / client / partner; trusted across all audits delivered on top of it. The pipeline version, discovery script version, and QA script version are stamped on every deliverable so any future audit can be matched to the exact methodology version that produced it.

- **The 25-FAQ section is structured by buyer journey**, not by topic alphabetization — Process & scope first (lowest-stakes questions a prospect asks), then Methodology & trust (the "is this real" gate), then What you receive, then Action & value, then Pricing & engagement (highest-stakes, asked last). This matches the order a prospect actually thinks through the questions, so the doc can be read top-to-bottom and feel like the answers arrive when expected.

- **Remote-hosting strategy locked: Cloudflare Tunnel + Access, NOT cloud hosting.** The strict-zero-cost + small-collaborator-group constraints make tunnel-based exposure of the existing local tool the correct architecture, not a stopgap. Cloud refactor is documented as a future trigger-driven decision, not a default trajectory. This avoids the trap of spending a week refactoring the tool to fit a hosting platform that doesn't materially improve the user experience for 2–4 collaborators.

- **Operator-Mac-must-be-online is an accepted constraint, not a problem to engineer around** at this scale. `caffeinate -i`, macOS wake-on-network, and a `launchd`-managed `cloudflared` cover the practical cases. Engineering around the constraint (full cloud refactor) only makes sense when triggered by a documented condition — see four trigger conditions in `docs/REMOTE-HOSTING.md` section 6.

- **Six paths explicitly rejected with stated reasons** rather than mentioned-and-skipped. Future re-litigation of the hosting decision can read the reference doc and find the reasoning instead of redoing the research. Particularly important for Render (which the operator already uses for other projects and might default to) — disqualified specifically for this tool by the 15-second edge timeout against a 10–15-minute pipeline.

- **No emojis used in any of the new docs** despite the documents being client-facing — held to the operator's stated preference. Authority comes from specificity (named frameworks, exact data points, named score weights), not visual decoration.
