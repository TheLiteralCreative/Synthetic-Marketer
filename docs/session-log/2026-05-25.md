**Decisions made:**

- **Two hand-written user LaunchAgents over `cloudflared service install`.** The official installer would have placed the tunnel as a system-level daemon while SignalRipper needs its own user agent — different locations, different commands, two ways to think about it. Hand-writing both gives one mental model and one `launchctl` workflow. The marginal automation `service install` provides isn't worth the inconsistency. Filed in Locked decisions.

- **Kit-auth chosen as the first concrete Ripper Kit module.** Rather than copy-pasting ScriptRipper's auth into SignalRipper, extract `app/api/auth.py` + `app/core/security.py` + `User` model as a reusable Kit module that both Rippers consume and future Rippers inherit. The first time a pattern needs a second consumer is the right moment to extract it — SignalRipper is that second consumer. Also gives the Ripper Kit a real, high-value module to start with rather than a generic skeleton.

- **Shared auth does not require shared hosting.** ScriptRipper stays on Render (paying customers + Stripe + SLA preclude operator-Mac dependency per `HOSTING-ROADMAP.md` §6 trigger conditions); SignalRipper stays on NODE_01; both consume the Kit-auth module. JWT-based identity makes one-login-every-Ripper trivially possible across hosts. v1: per-Ripper User tables (slight friction approving on each Ripper the first time, with clean per-Ripper access control as a side benefit). v2 (when there are 3+ Rippers and several real users): shared identity DB or service.

- **SQLite for SignalRipper's user table.** Matches NODE_01's local-disk model; no external DB dependency to manage. SQLAlchemy keeps the schema interchangeable with ScriptRipper's Postgres.

- **Cloudflare Access on `signalripper.literalcreative.com` is the temporary v1 gate.** Existed because we needed a gate fast and didn't want to write auth code. Comes off when Kit-auth lands on SignalRipper — so the "the Cloudflare gate is an issue" concern resolves itself by completing the Kit-auth retrofit, not by working around the gate.
